# C# Null Safety

## Overview

This example demonstrates how to safely handle
null values in C# using Unity.

## Concepts Demonstrated

- Null Conditional Operator (?.)
- Null Coalescing Operator (??)
- Safe property access
- Safe method invocation
- Default values for null references

## How to Run

1. Import NullSafetyExample.cs into a Unity project.
2. Attach the script to a GameObject.
3. Open the component's context menu in the Inspector.
4. Select NullGuvenlikTesti.
5. Check the Unity Console.

## Expected Output

```text
0
5
MERHABA ATLAS
Mesaj Bulunamadı
```

## Learning Outcome

Understanding how to handle null references
safely and prevent NullReferenceException.
